Quick and Easy Access to Your Database with TMS Tool Management Solutions from ZOLLER

With ZOLLER’s TMS Tool Management Solutions software, manufacturing companies can quickly and simply create a comprehensive database for digitized tool management.

Download

Quick and Easy Access to the DatabasePDF · 389 KB

Data System with ZOLLER TMS Tool Management Solutions

Christoph Zoller, managing director of E. Zoller GmbH & Co. KG—a family-owned technology company based in Pleidelsheim that specializes in the cost-effective handling of cutting tools—addresses the reservations that medium-sized manufacturing companies have about digitizing tool organization and management: “With our TMS Tool Management Solutions software, users can import data at the touch of a button from individual spreadsheets, catalogs, and the Internet.” This allows them to quickly and conveniently lay the foundation for the extensive digitization of internal processes related to the use of cutting tools.

Minimal effort, comprehensive benefits

Among the outstanding advantages of digitized tool management are:

  • Transparency
  • Quickly finding tools
  • Up-to-date, correct tool data anytime, anywhere
  • Optimized tool inventory
  • Minimized effort in procurement, logistics, and store management
  • Maximum process reliability

All areas involved in manufacturing benefit from these advantages: Purchasing, CAD design, CAD/CAM programming, tool preparation—including measurement, adjusting, assembly, and dismantling—the tool warehouse, and machine set-up personnel. Production itself minimizes downtime and the risk of damage to machines and tools caused by collisions.

Flexible import of master data

Regarding the creation of master data for digitized tool management, Robin Bender, project manager for the TMS Tool Management Solutions software at ZOLLER, says: “Our software can be flexibly used to correspond to specific requirements. For example, master data can be imported quickly and simply from the commonly used spreadsheets in standard Excel software.” ZOLLER provides a standardized spreadsheet (a template) for this purpose. The TMS Tool Management Solutions software imports tool data from this spreadsheet in a very short time and saves it in the designated fields. The data from existing custom spreadsheets only needs to be converted to match ZOLLER’s standard spreadsheet format—that is, entered into the corresponding columns. “Of course, we support our customers with conversion software. We only need the formatting of the individual spreadsheets. Then the tool data can be transferred to our tool management software using a keystroke,” explains Robin Bender.

Hundreds of tools in one go

Robin Bender designates importing data via the ToolsUnited internet platform from Cimsource in Aachen (www.cimsource.com) as another very convenient and fast method for data acceptance. It is called up directly from within the ZOLLER software. “There, you’ll find primarily standard tools from a wide range of internationally active Tool manufacturers for selection. You can select each one individually with a mouse click and start the data acceptance,” reports Robin Bender.

Interface for Direct Import

An interface for this purpose is integrated into the ZOLLER software. It allows individual tools to be imported using the manufacturers’ article numbers. Optionally, users can filter by machining process and display comprehensive lists. The selection can be refined using additional criteria—such as diameters, lengths, and number of cutting edges. After a keystroke, the selected tools are imported into the TMS Tool Management Solutions software. Only a unique ID number is required.

Importing Tool Lists

Optionally, it is possible to automate this process for entire tool lists. This makes it possible to enter a comprehensive selection of standard tools into the tool management software in a very short time with minimal effort. Especially, the software contains standardized tool parameters provided by the manufacturers, as well as 3D graphics for current CAD/CAM programming and simulation systems, if desired. When investing in ZOLLER software, you only need to purchase a (time-limited) license for the ToolsUnited internet platform.

Directly from the manufacturer

If manufacturing companies primarily work with tools from only one or a few manufacturers, it is also worthwhile to automate data acceptance directly from those manufacturers’ digital catalogs on the Internet. However, data acceptance depends on the options provided by the respective manufacturers. Robin Bender comments: “Some tool manufacturers manufacture exclusively complete catalogs as data records, while others also offer selection criteria, such as by article characteristics. With the latter, you can import individually predefined lists of tools.” This is possible because the master data for the tools is stored and designated in a largely standardized manner.

Custom Editing

Robin Bender adds: “Of course, specialists can further edit the automatically imported tool data individually within the ZOLLER software. For example, you can use the editing function to assign your own master data numbers or add additional fields for selection from lists.”

Defining Individually, Especially for Specialized Tools

When manufacturing companies work with custom tools, these can be defined and saved in the TMS Tool Management Solutions software using input fields with a wide range of parameters and criteria. “First, personnel select a machining process for the tool to be created, such as milling. They then see a master data sheet for milling tools on the screen. This sheet contains the geometries and parameters to be defined for this tool category,” reports Robin Bender.

First, an ID number must be assigned, followed by the data describing the respective tool. Robin Bender comments: “The advantage of our tool management software is that data that does not necessarily need to be specified individually is already provided with default values. Therefore, just a few parameters are usually sufficient to define a tool adequately for use in tool management.” These include, for example, some basic dimensions. Further details, such as radial relief angles on cutting edges and similar geometries, can be specified exactly later, to the extent that this is required for use in CAD/CAM systems, in the default setting, and on CNC machines.

Plausibility check included

This individual data entry is optionally available in the TMS Tool Management Solutions software for monoblock tools—such as solid carbide milling cutters—and for assembled complete tools. For the latter, automatic plausibility checks in accordance with DIN 4000 ensure that only sensible and technicaly feasible complete tools are specified and saved. In this way, ZOLLER’s software ensures maximum process reliability.

Creating Complete Tools from Existing Components

If components are already contained in the tool management software, complete tools can be created partially automatedly. To do this, personnel only select the required components, such as the tool holder, collet chuck, and solid carbide drill. After checking for compatible geometries, the ZOLLER software automatically assembles the complete tool. To save the tool, a master number is specified, thereby creating a separate data record. The tool management software automatically generates a 3D model (solid model) for CAD/CAM programming and simulation.

Expert Service from Specialists

When installing the TMS Tool Management Solutions software, as well as when performing selections and creating master data, ZOLLER’s specialists naturally support professionals in manufacturing

manufacturing operations. “We want to pave the way, especially for smaller companies, toward comprehensive digitization with all its benefits. To this end, we make our extensive expertise and practical industrial experience available. Users can fully rely on the know-how of our qualified experts. We provide detailed advice on the optimal methods for entering data into our software in each case. In addition, we have designed the software to be largely intuitive for its operation. This means that even personnel with little experience in handling software can, after minimal training, successfully and profitably use our tool management software in no time,” highlights Christoph Zoller.
